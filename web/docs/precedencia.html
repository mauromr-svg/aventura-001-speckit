Como a sala escuta

Ordem de precedência

Uma sequência pode combinar com mais de uma regra. O eco testa padrões específicos em uma ordem fixa e escolhe o primeiro que explica todos os números.

  1. Constante: todos os números são iguais.
  2. Aritmética: a diferença entre termos é constante.
  3. Geométrica: cada termo é o anterior multiplicado pela mesma razão.
  4. Fibonacci: cada termo é a soma dos dois anteriores.
  5. Polinomial: diferenças sucessivas ficam constantes, de grau 2 a 5.

Por que 2, 4, 8 responde 16?

Os termos dobram: 2 × 2 = 4 e 4 × 2 = 8. A progressão geométrica vem antes de qualquer regra polinomial, então a sala prevê 8 × 2 = 16.

Com exatamente dois números, o eco assume uma progressão aritmética: 2, 4 → 6. Para os outros padrões, são necessários mais termos para confirmar a regra.

Mínimos: constante e aritmética, 2 números; geométrica, 3; Fibonacci, 4; polinomial de grau k, k + 2 números.
