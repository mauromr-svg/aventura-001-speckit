Padrão 4

Sequência de Fibonacci

Cada termo nasce da soma dos dois termos anteriores.

Como reconhecer

A partir do terceiro termo, some os dois que vêm antes. Para confirmar esse padrão, o eco exige pelo menos quatro números.

Em 1, 1, 2, 3, 5, cada termo a partir do terceiro é a soma dos dois anteriores. O próximo é 3 + 5 = 8.
