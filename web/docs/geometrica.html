Padrão 3

Progressão geométrica

Cada termo é o anterior multiplicado por uma razão.

Como reconhecer

Divida um termo pelo anterior. Se o quociente (a razão) for sempre o mesmo, multiplique o último termo por essa razão para encontrar o próximo.

A razão pode ser fracionária. Por exemplo, 9, 6, 4 usa razão 2/3; o próximo é 8/3.
