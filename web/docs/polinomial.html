Padrão 5

Sequência polinomial

As diferenças entre termos também formam um padrão.

Como reconhecer

Subtraia termos vizinhos para criar a primeira linha de diferenças. Se ainda não houver uma diferença constante, repita o processo. Quando uma linha fica constante, o grau do padrão é o número de repetições.

Quadrados perfeitos: 1, 4, 9, 16. As diferenças são 3, 5, 7; as diferenças delas são 2, 2. O próximo número é 25.

O eco reconhece graus de 2 a 5 e exige termos extras para confirmar a regra.
