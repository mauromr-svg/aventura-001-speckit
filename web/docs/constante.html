Padrão 1

Sequência constante

O mesmo número aparece em todas as posições.

Como reconhecer

Compare os termos: se todos têm o mesmo valor, a sequência é constante. O próximo número repete esse valor.

Exemplo: 7, 7, 7 → 7. O eco verifica sequências constantes antes das outras regras.
